# HERMES.md — WhatBusinessInTangsel

System manual for Hermes Agent sessions. Read this first, every turn. Highest-priority project context.

## 1. Mission

Interactive **Business Prospect Analytics** dashboard for Kota Tangerang Selatan: pick a sector + kecamatan, get a relative explorative index, map overlays, and side-by-side comparison.

**Current phase: Gates 0–3 complete — 6 sourced indicators, 3 sectors, pipeline with QC.** Figures are traceable to Dukcapil DKB PDFs (SHA-256 pinned) and an OSM Overpass snapshot (ODbL); see `docs/gate1/ledger.md`. What is *not* settled: weights are designer judgement (not calibrated), the Dukcapil publication licence has no open clause, and OSM boundaries are not a BIG/Kemendagri authority. The dashboard is a relative exploratory index — never a business-feasibility ruling.

Deliverable = Next.js dashboard deployed on Netlify, used as a **Business Analyst portfolio piece** for Cantikaputri Febrianti. Public-facing bar: every number shown must be traceable to a raw source file plus a documented transform, or be visibly labelled as an assumption/scenario.

## 4. Verification Gate (baseline, must all pass)

Data gate: `npm run data:build` (11 QC) dan `npm run data:qc` (4 mutation checks + healthy control) harus lulus sebelum Gate 3/4.

```bash
npx next lint                          # ESLint via .eslintrc.json (next/core-web-vitals)
npx tsx test-engine.js                 # scoring + recommender + label contract, 10 cases
npx tsx --test tests/ui.test.js        # SSR render suite, 6 subtests
npm run build                          # next build + type check, 4 static pages
```

`npm test` runs the two tsx suites. Node 24 + `tsx@4` is required — plain `node` cannot import the `.ts` engine or JSON modules with the import-attribute rule Node 24 enforces.

Known-good baseline (verified 2026-10-20, Gate 3): lint clean, 10/10 engine cases, 6/6 UI subtests, data QC 11/11 + selftest 5/5, build ✓ 4/4 static, route `/` ~170 kB First Load JS.

## 5. Guardrails

- **Sourced data only — never edit it by hand.** `docs/gate2/verified_dataset.json` is generated by `npm run data:build`; the typed bridge is `src/data/verifiedDataset.ts`. The old concept files are archived under `docs/gate1/concept_data_archive/` and must not be re-imported by runtime code. `calculateScore` throws on a missing kecamatan, sector, POI count or normalizer — missing is never treated as zero.
- **Scoring contract (Gate 3)** lives in `src/lib/engine/scoring.ts`: 6 indicators, weights `0.20/0.20/0.15/0.15/0.15/0.15` (sum exactly 1.00), ×10, rounded to 1dp, clamped 1.0–10.0. Normalizers are **data-derived maxima** from `docs/gate2/verified_dataset.json` (11.797; 339.054; 0,3297; 0,7433; retail 4,97 / health 1,39 / education 7,51; 8), never hardcoded literals. `test-engine.js` asserts the weight sum, every threshold boundary, and that `recommender.suitability === scoring.label` across all 21 combinations — change one, change all.
- **One label vocabulary.** `labelForScore()` is the only threshold table; `recommender.ts` reuses it. Never reintroduce a second threshold block, and never use verdict language ("Layak"/"Tidak Layak") — this is a relative exploratory index, not a feasibility ruling.
- **Missing data throws, never becomes 0.** `calculateScore` raises on a missing POI count or normalizer instead of falling back to `|| 0`, which would read as "no competition" and hand out a false top rank.
- **Client-only map**: `MapComponent` is `dynamic(..., { ssr: false })` because Leaflet touches `window` at import time. Never import it statically.
- **JSON imports must stay default imports** (`import x from './x.json'`). Named JSON imports caused a client-side exception (commit 8325503).
- **Chart.js controllers** must be registered in `ChartsPanel.tsx` (commit ab2f8ab). A missing controller throws at runtime, not at build.
- **Only claim what an artifact proves.** Every figure must trace to `docs/gate1/source_manifest.json` (SHA-256) plus `docs/gate1/ledger.md`. Never describe the tool as producing business-feasibility verdicts, and never label OSM POI counts as "jumlah kompetitor" — they are *kepadatan POI terpetakan* (measured bias 1,25×–5,75×, inverted at Setu).
- **No `response.ok`-free fetches, no `any` escapes** in new code unless the surrounding file already does it.
- Static assets for download links go in `public/`, not `src/`.
